# 01：光と影（2026-11-22〜23）

## 何を変えたか
- 太陽の向きを「真上寄り」から**低い斜め（地平線から 30 度）**に変えた。長い影が出るようになった
- 太陽の向きを、カメラから見て斜め前から当たる方角にした（機体の見えている面が明るくなる）
- 太陽を少し暖色・強め（明るさ 1.45）にし、影のふちをわずかにぼかした
- 影が届く距離を 100m → **200m** に伸ばした（遠くの機体や遮蔽物にも影が出る）
- 反対側から弱い**寒色の補助光**を足し、機体の裏側が真っ黒にならないようにした

## 採点（Codex・厳しい批評役・思考の深さ最大）
| 回 | 変更前 | 変更後 | 批評の要点 |
|---|---|---|---|
| 1 回目（後処理） | 2.0 | **1.5** | 影が黒くつぶれ立体感が落ちた → **取り消し** |
| 2 回目（後処理やり直し） | 2.0 | **1.8** | まだ黒つぶれ。2 回で改善せず → **取り消し**（規則どおり次へ） |
| 3 回目（光と影） | 2.0 | **2.5** | 斜めに伸びる影で、機体と遮蔽物が地面に立つ感覚が出た → **採用** |

批評役が挙げた「次の一番の弱点」：ボス戦の画面で要塞の姿が読み取れない（手前の構造物が画面を占める）

## 確認したこと
- 自動テスト：**31 本すべて成功**
- フレームレート：変更前 70〜108、変更後 67〜111（この PC では計測値が大きく揺れるため、**どちらも 60 を下回らない**ことだけが確かで、変更による正確な負荷差は**未確認**）
  - 影の距離を 320m にすると重くなったため 200m に下げた
- 利用量：週の枠を 36% 使用（この項目の作業時点）
