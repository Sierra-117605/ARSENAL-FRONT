# 02：地面と空（2026-11-23）

## 何を変えたか
- 地面の見た目を**格子模様から土とコンクリートのムラ**に作り替えた（`shaders/ground.gdshader`）
  - 画像ファイルは使わず、すべて計算で作っている：大きなムラ（100m くらい）、中くらいのムラ、砂のざらつき、舗装の継ぎ目
  - 近くだけ細かい凹凸を出し、遠くはなめらかにして、ちらつきと負荷を抑えている
- 空の色を落ち着いた軍事風にした（上は深い青灰、地平線は砂混じりの明るい灰）
- 遠くがかすむ**霞（フォグ）**を薄く入れた。奥行きが出て、硬い地平線の線がやわらいだ
  - 最初は濃すぎて画面が真っ白になったので、濃さを 1/3 に下げた
