## ここから分かったこと
- 批評役の指摘は毎回「箱を並べた形に見える」に収束している。
  箱と円柱を足すやり方では、これ以上点数が動かない見込み
- 次に効くのは、**角を落とした形・傾斜した装甲そのものを作ること**（＝ TODO N8-3 の 3D モデル作成、
  または形状を計算で作る作り直し）。これは開発者の決定が必要な範囲（3D モデルの作り込み）
