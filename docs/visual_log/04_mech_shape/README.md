# 04：機体の形の作り直し（2026-11-23）

## 何を変えたか
SPEC §0.18（開発者の好みから取り出した「形の特徴」）に沿って、**形そのもの**を作り替えた。
3D モデルのファイルは使わず、すべて計算で作っている。

- `scripts/action/mesh_shapes.gd` を新設：**角を落とした八角柱（上下で大きさを変えられる台形）**と
  **くさび形**を計算で作る土台。箱のままだと影の線が 1 本しか出ないが、角を落とすと
  平らな面と斜めの面の境目に線が出て、装甲らしく見える
- 胴・頭・腰・肩・脚・足・背面ユニットの形を、この八角柱に差し替えた
  - 胸は上が広く腰に向かって細い／脚は上が太く足首に向かって細い（§0.18 の「細い腰と長く太い脚」）
  - 背面ユニットを大きくし、推進器と放熱板を付けて後ろ側の輪郭を大きくした
- 肩当て・スカート装甲・すね当て・胸の傾斜装甲を重ね、**肘と膝の軸、動力シリンダー**を外から見えるようにした
- 質感を 3 種類に分けた：塗装した装甲（つや消し・縁にうっすら光）／むき出しの金属（反射強め）／発光する計器
- 既存のノード名・当たり判定・部位ダメージ・銃口の位置には触れていない
