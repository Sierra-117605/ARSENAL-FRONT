オリジナルの3Dメカアクションゲーム『ARSENAL FRONT』の主役機をデザインしてください。今回は全身の決定稿候補を1案だけ、斜め前から見たコンセプトアートとして描いてください。

頭部は前回決めた形をそのまま使ってください。上面を覆う大きな一枚の庇が前へ張り出し、上から見ると前が尖った六角形。庇の後ろの付け根は厚く、前の縁は薄く抜ける。庇の下面は暗い。その影の奥に、細く切れ長の二つの光学センサーが淡い水色に光る。顔は面長で、頭頂を高く盛らず、センサーから顎の下端までに長さがある。側頭部から後方へブレード状の突起が数枚、斜め上後ろへ伸びる。顎から首にかけてリンク機構とケーブルが露出している。

機体は軽量・高機動型の人型。欲しい印象は「アーマード・コア フォーアンサーの世界で運用されていそうな、ガンダム系の主役機」です。ガンダムから借りたいのは、一目で主役だと分かる気品と、機械なのに意志を感じる立ち姿。ACから借りたいのは、高速で動く機体としての説得力と、装甲の隙間から構造を想像できる面白さです。既存機の意匠・配色はそのまま写さず、独自の機体にしてください。

体型は次のとおりにしてください。

- 肩は大きく左右に張り出し、上へ跳ね上がるライン。胴体より肩の幅が広い
- 胸は前へ大きく張り出し、中央に縦の稜線が一本通る
- 腰は細く絞り、前面に大きなスカート装甲を置く
- 脚は長く太い。立ち姿に重心の低さと重量感がある
- 背中に大きな推進ユニット（噴射口と放熱板）。機体の輪郭を後ろ側で大きく見せる
- 肘・膝・足首の関節に、装甲に隠れない機構（軸・シリンダー・配管）が見える
- 武器は持たせず、手は開いた状態

装甲は大きく潔い面を残し、全面をパネル線やボルトで埋めないでください。各部に厚みのある付け根と薄く抜ける縁を作り、近くで見ると部品の前後関係が分かること。縮小しても輪郭が格好いいこと。

塗装は明るい灰青の半つや消し。内部と関節は濃い青灰色。小さな整備表示にだけオレンジを使い、センサーの発光は控えめに。激しい汚しや逆光で形を隠さず、柔らかい斜光で装甲の面と厚みを見せてください。

構図は全身が入った、目線の高さの斜め前。無地の背景。文字、ロゴ、武器、別案、三面図は不要です。ゲームの美術監督が「この形を立体にしたいか」を判断できる一枚にしてください。
