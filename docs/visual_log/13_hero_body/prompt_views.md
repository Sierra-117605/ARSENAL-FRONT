# 主役機の三面図を描かせるプロンプト（2026-11-23）

斜め前の決定稿（`reference/ref_body.jpg`）だけでは、横幅と前後の厚みを目分量で推測するしかない。
**正面・真横・背面**を同じ縮尺で描かせ、Blender で寸法を読み取れるようにする。

使い方：**1 枚ずつ**投げる。まとめて「三面図」と頼むと配置が崩れるため。
いずれも **`reference/ref_body.jpg` を添付**し、「同じ機体」であることを明示する。
出てきた画像は `reference/` に `view_front.jpg` / `view_side.jpg` / `view_back.jpg` で保存する。

---

## 1. 正面図

添付の画像と同じ機体の、真正面から見た図を描いてください。デザイン・配色・各部の比率は添付と完全に同じにし、新しい装備や意匠を足さないでください。

- 直立した姿勢。両腕は体の横に下ろし、武器は持たせない
- 遠近をつけず、正投影のように描く。視点の高さは機体の中央
- 機体の全身が入る。頭頂と足の裏に、同じだけの余白を取る
- 左右対称
- 背景は無地の薄い灰色。影、効果、文字、ロゴ、寸法線は描かない
- 柔らかく均一な光で、装甲の面の向きと板の厚みが読めるように

## 2. 真横（側面図）

添付の画像と同じ機体の、真横から見た図を描いてください。デザイン・配色・各部の比率は添付と完全に同じにし、新しい装備や意匠を足さないでください。

- 機体の左側面から見た図。機体の正面は画面の右を向く
- 直立した姿勢。両腕は体の横に下ろし、武器は持たせない
- 遠近をつけず、正投影のように描く。視点の高さは機体の中央
- 機体の全身が入る。頭頂と足の裏に、同じだけの余白を取る（正面図と同じ縮尺）
- 頭の庇がどれだけ前へ出ているか、胸がどれだけ前へ張り出しているか、背面の推進ユニットがどれだけ後ろへ出ているかが分かるように
- 背景は無地の薄い灰色。影、効果、文字、ロゴ、寸法線は描かない
- 柔らかく均一な光で、装甲の面の向きと板の厚みが読めるように
