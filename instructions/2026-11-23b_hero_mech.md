### 3-1. 残っている指摘を直す（まずこちら）

### 3-2. 主役機をヒロイックな形にする
`SPEC.md` §0.18 の「主役機と量産機を作り分ける」に従う。要点：
- 顔：**SPEC §0.18「顔（頭部）の作り方」に従う**（2026-11-23 第 42 版で追加。必ず読むこと）
  - 庇の下に左右 2 つのレンズ、中央に縦の稜線、下端に横スリット、側頭部カバー、額に細い突起 1 本
  - 顔の部品は 5〜8 個。大きな面を残さない。首の機構（シリンダー等）を見せる
  - **主役機の顔は 4 案作る**：`docs/visual_log/11_hero_face/` に同じ角度（正面・斜め・横）で並べ、
    `HANDOFF.md` に書いて**開発者の選択を待って止まる**。選ばれてから全身に組み込む
  - 開発者の指摘：これまでの顔は「箱＋庇＋丸い目」の 3 要素しかなく、好みではない
- 胸：大きく張り出した胸部装甲。中央に縦の稜線
- 肩：左右対称で**上へ跳ね上がる**ライン。量産機より一回り大きい
- 腰：前面のスカート装甲を大きく
- 色：量産機より明るく、差し色を 1 色だけ（発光部とは別に）
- **厳守**：既存作品の象徴的な意匠（特定のアンテナ形状・顔の造形・配色の組み合わせ）をそのまま使わない

作り方（2026-11-23 Claude Code が設計を確定。迷わず進めてよい）：
- `tools/blender/mech_b.py` を**量産機用**として残し、主役機用に `tools/blender/mech_hero.py` を作る
  （共通の部品を作る関数は切り出して共有してよい）。書き出し先は `assets/models/mech_hero.glb`
- **どの機体が主役機か**：`Robot` クラスに `@export var hero: bool = false` を足し、
  戦場シーン `scenes/field_3d.tscn` の **`Robot` ノードだけ `hero = true`** にする。
  `SpareRobot`・`Enemies/*` は false のまま（＝量産機）。
  プレイヤーが乗り換えても、主役機はこの 1 機で固定（見た目が入れ替わらないようにするため）
- 読み込み：`hero` が true なら `mech_hero.glb`、false なら `mech_b.glb` を使う。
  どちらも無ければ今までどおり計算で作った形にする（**ファイルが無くても動くこと**）
- **色**：主役機は量産機より明るい灰青（例 RGB 0.42/0.47/0.52 あたり）を下地にし、
  差し色はオレンジを 1 色だけ（胸の稜線・肩の縁・膝の帯など、面積の小さい所に）。
  発光部は今までどおり別扱い。量産機の灰緑は変えない
- **大きさ**：主役機は量産機と同じ全高のまま（ゲームの当たり判定・性能を変えないため）。
  大きく見せるのは形（肩の張り出し・胸の厚み）で行う
